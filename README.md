## SFS 中文注入器
###  两种汉化模式

| 模式 | 做什么 | 留下什么 | 汉化是否需进程运行 |
|------|--------|----------|----------------|
| **本体汉化** | 把社区中文词表 `简体中文（汉化）.txt` 放进游戏 `Spaceflight Simulator_Data/Custom Translations/` | 仅多这一个 txt | 否 |
| **DLL 汉化** | 把 Mod 的中英文替换成中文 统一中文字体 | 注入模式下 Mods 目录**不动** 可选把运行时 Mod 装进 `Mods/SFSHanRuntime` | 是 |
###  三类实际能力

1. **本体翻译文件**：复制并过滤词表到游戏目录 写 `LanguageSettings_2.txt` 切到该语言
2. **运行时注入翻译**：把托管 Mod 从内存加载进游戏 Mono 用 Harmony 接管所有文本渲染做翻译 + 换字体 零落盘
3. **离线静态改写 DLL**：直接改 Mod 的 `#US` 字符串堆 把英文常量替换成中文 靠备份/清单/还原/校验保证安全 改后 Mod 自己就带中文
